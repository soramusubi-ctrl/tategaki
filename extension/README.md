# 縦読みの部屋 for Substack

Substackの記事ページに「縦読み」ボタンを追加するChrome拡張です。

## 動作

1. Substackの記事を開く
2. 右下の「縦読み」を押す
3. 表示中の記事タイトルと本文を抽出
4. 縦読みの部屋へ保存
5. `/s/短いID` の読書ページを新しいタブで開く

## Chromeへの入れ方

1. この `extension` フォルダをPCに保存する
2. Chromeで `chrome://extensions/` を開く
3. 右上の「デベロッパーモード」をオン
4. 「パッケージ化されていない拡張機能を読み込む」
5. `extension` フォルダを選ぶ

## 対応範囲

- `https://*.substack.com/p/*` の記事
- ページ上に実際に表示されている本文
- 公開記事、またはログイン中に閲覧できる記事

## 注意

Substackの画面構造が変更された場合、本文抽出セレクタの調整が必要になることがあります。
